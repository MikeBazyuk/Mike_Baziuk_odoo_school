===========
HR Hospital
===========

Навчальний модуль управління лікарнею для Odoo 19.0, розроблений в рамках курсу `Odoo School <https://odoo.school/>`_.

.. contents:: Зміст
   :depth: 2

Опис
----

Модуль реалізує базову систему управління лікарнею:

* Облік лікарів (спеціальність, кваліфікація, ментор / інтерни)
* Облік пацієнтів (страховий поліс, персональний лікар)
* Запис на прийом із статусами та захистом завершених візитів
* Ієрархічний класифікатор хвороб
* Розмежування прав доступу (5 груп з успадкуванням)
* Друкований HTML-звіт по лікарю
* Повний комплект уявлень (form, list, kanban, calendar, pivot, graph, search)

Вимоги
------

* Odoo >= 19.0
* Python >= 3.10
* Модуль ``base``

Встановлення
------------

1. Скопіюйте директорію ``hr_hospital`` до папки ``custom_addons``::

       cp -r hr_hospital /path/to/odoo/custom_addons/

2. Додайте шлях до ``addons_path`` у ``odoo.conf``::

       addons_path = /path/to/odoo/addons,/path/to/custom_addons

3. Оновіть список застосунків та встановіть модуль::

       ./odoo-bin -u hr_hospital -d <db_name> --stop-after-init

Конфігурація
------------

Групи доступу
~~~~~~~~~~~~~

Призначте користувачам відповідні групи в меню
*Налаштування → Користувачі → Групи*:

+---------------+--------------------------------------------------------+
| Група         | Права на відвідування                                  |
+===============+========================================================+
| Пацієнт       | Читання власних (де patient_id.user_id = current user) |
+---------------+--------------------------------------------------------+
| Інтерн        | Читання + редагування власних (як лікар)               |
+---------------+--------------------------------------------------------+
| Лікар         | Читання + редагування своїх та інтернів                |
+---------------+--------------------------------------------------------+
| Менеджер      | Читання всіх відвідувань                               |
+---------------+--------------------------------------------------------+
| Адміністратор | Повний доступ CRUD до всіх даних модуля                |
+---------------+--------------------------------------------------------+

Щоб прив'язати пацієнта до користувача системи, заповніть поле
**Користувач системи** у картці пацієнта.

Зв'язок лікаря з користувачем виконується через поле **Користувач системи**
у картці лікаря.

Тести
-----

Запуск тестів::

    ./odoo-bin -u hr_hospital -d <test_db> --test-enable --stop-after-init

Тести покривають:

* ``Doctor._compute_is_intern`` — обчислення статусу інтерна
* ``Doctor._compute_is_mentor`` — обчислення статусу ментора
* ``Doctor._check_mentor_not_intern`` — заборона призначення інтерна ментором
* ``Visit.write`` — захист полів завершеного візиту
* ``Visit.unlink`` — заборона видалення завершеного візиту
* ``Disease._check_parent_recursion`` — захист від циклічності в ієрархії хвороб
* ``Disease._compute_display_name`` — формування повного шляху назви хвороби
