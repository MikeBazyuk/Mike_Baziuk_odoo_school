🏥 HR Hospital

Навчальний модуль управління лікарнею — розроблений у рамках курсу Odoo School.

Odoo 19.0 Python QWeb Reports Ukrainian

📋 Опис

Модуль HR Hospital реалізує базову систему управління лікарнею: облік лікарів та пацієнтів, запис на прийом, класифікатор хвороб, розмежування прав доступу та друковані звіти.

✨ Функціональність

БлокМожливості
ЛікаріКартка лікаря, спеціальність, кваліфікація, ментор / інтерни, kanban-дошка
ПацієнтиКартка пацієнта, страховий поліс, персональний лікар, лічильник візитів
ВідвідуванняСтатуси (Заплановано / Завершено / Скасовано), захист від редагування завершених візитів
ХворобиІєрархічний класифікатор хвороб із кодами
ЗвітиДрукований звіт по лікарю: картка + візити + пацієнти
БезпекаГрупи: Пацієнт / Інтерн / Лікар / Менеджер / Адміністратор

🔐 Групи доступу

ГрупаВідвідуванняПримітка
ПацієнтЧитання власнихБачить лише свої відвідування
ІнтернЧитання + редагування власнихУспадковує права Пацієнта
ЛікарЧитання + редагування своїх та інтернівУспадковує права Інтерна
МенеджерЧитання всіхУспадковує права Лікаря
АдміністраторПовний доступ (CRUD)Успадковує права Менеджера

📊 Моделі

  • hr_hospital.doctor — Лікар
  • hr_hospital.patient — Пацієнт
  • hr_hospital.visit — Відвідування
  • hr_hospital.disease — Хвороба (ієрархічна)
  • hospital.doctor.category — Кваліфікація лікаря
  • hospital.doctor.history — Історія персональних лікарів
  • hospital.medic.info — Абстрактна модель медичної інформації

🛠 Встановлення

  1. Скопіюйте директорію hr_hospital до папки custom_addons.
  2. Додайте шлях до addons_path у odoo.conf.
  3. Перезапустіть сервер Odoo: ./odoo-bin -u hr_hospital -d <db_name>
  4. Активуйте модуль у меню Застосунки.
